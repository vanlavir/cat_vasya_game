# Игра от кота Василия

Это небольшое задание по ООП на Python. В проекте реализованы классы для
простой ролевой игры: персонажи, их характеристики, система маны и заклинания.

Проект разделён на несколько файлов.

В файле unit.py расположен общий абстрактный класс Unit. В нём содержатся
основные параметры персонажа: сила, ловкость, телосложение, мудрость, интеллект
и харизма. Также в этом классе предусмотрены список заклинаний и запас маны.

В файле character.py находится класс Character. Персонаж может относиться к
одному из трёх классов: warrior, mage или hunter. В зависимости от выбранного
класса рассчитываются урон, защита и максимальный запас маны.

В файле spell.py описаны заклинания. Там находится общий абстрактный класс
Spell, а также три конкретных заклинания: Fireball, IceLance и LightningBolt.

В файле main.py приведён пример работы программы. В нём создаются три
персонажа, отображаются их характеристики и демонстрируется применение
заклинания.

Для запуска программы необходимо открыть папку проекта и выполнить команду:

python main.py

После запуска программа показывает характеристики персонажей и пример
использования заклинания магом.
